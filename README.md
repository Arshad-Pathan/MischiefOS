### Features 
---
1. Read guide to know all features.
1. Boot Screen with booting animationa and sound
2. Lock Screen with Bento Grid Style and lots of widgets
   > Made with details to feel real desktop lock screen
   - time
   - Music Widget
   - images
   - visit counter
   - weather widget
   - qoute widget
   - apps
3. top bar Features: 
   - can be change appearance from setting
   - os name
   - visitor counter
   - weather
   - timer 
   - time display
4. Analog clock Displays time of 3 different time zones Including:
   1. Asia/kolkata
   2. Pacific/Chatham
   3. Pacific/Apia
   - can be hide from setting 
5. Intro 
   - Shows Intro Details about My OS with Inspiration book
   - Link to my Github Repo
6. Journal
   - A real TVA(A organization in Series) Inspired Journal book
   - can add or make and save notes.
   - pagination.
7. Wallpaper can be changed from setting, also can upload custom
8. terminal features various commands, explore by typing "help"
9. music player contains 4 musics with vinyl player.
10. wikipedia shows some inside of tva
11. library is something different, just explore it yourself to be amazed.
12. gallery also contains some very exciting contents.
13. please don't leave without playing mygame. see animations.
14. there are lots of things i made, explore all the os to exprience yourself.
